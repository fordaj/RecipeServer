# COGNITIVE_COMPLEXITY_AGENT

## Create issues

```text
In a separate worktree using the latest commit on main, audit the codebase against the guidelines inside of ./agents/COGNITIVE_COMPLEXITY_AGENT.md. Create a parent issue "[COGNITIVE COMPLEXITY] Parent Issue". The top 10 source files, ordered by most-to-least severely violating the guidelines should have a child issue created titled "[COGNITIVE COMPLEXITY]: <filename>", and the issue body should contain instructions to fix. The assigned agent will be referred to the same guidelines, so do not restate them.
```

## Work on an issue

```text
Please complete issue #X in a separate worktree off of the most recent commit on main. Your branch should be prefixed "cognitive-complexity/issue-<issuenum>-<filename>/<your model name>. Follow the guidelines inside of ./agents/COGNITIVE_COMPLEXITY_AGENT.md. Upon completion, publish your branch and create a PR into main. If your branch is not on main at this time, rebase and resolve conflicts, ensuring your edits are still valid and tests pass.
```
